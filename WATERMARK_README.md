# Водяной знак с изображением

## Как использовать свой логотип

Функция `add_watermark()` теперь поддерживает добавление изображения в качестве водяного знака.

### Быстрый старт

1. **Создайте свой логотип** (PNG с прозрачностью рекомендуется)
2. **Сохраните его** как `static/watermark_logo.png`
3. **Готово!** Логотип будет автоматически добавляться на обработанные изображения

### Примеры использования

#### Использование логотипа по умолчанию
```python
processed_img = add_watermark(processed_img, text="Обработано", logo_path="static/watermark_logo.png")
```

#### Только текст (без логотипа)
```python
processed_img = add_watermark(processed_img, text="Обработано")
```

#### Только логотип (без текста)
```python
processed_img = add_watermark(processed_img, text="", logo_path="static/watermark_logo.png")
```

#### Свой логотип
```python
processed_img = add_watermark(processed_img, text="© 2025", logo_path="static/my_custom_logo.png")
```

### Параметры функции

- `img` - исходное изображение (PIL.Image)
- `text` - текст водяного знака (по умолчанию: "Обработано")
- `logo_path` - путь к файлу логотипа (опционально)

### Особенности

- Логотип автоматически масштабируется (не более 15% от ширины изображения)
- Применяется прозрачность 70% для ненавязчивого вида
- Размещается в правом нижнем углу
- Если указан и текст, и логотип - текст размещается над логотипом
- Если логотип не найден - используется только текст

### Создание собственного логотипа

Запустите скрипт для создания примера:
```bash
python create_logo.py
```

Это создаст файл `static/watermark_logo.png` с простым логотипом "WM" в синем круге.

**Замените этот файл своим логотипом!**

### Рекомендации для логотипа

- Формат: PNG с альфа-каналом (прозрачность)
- Размер: 200x200 пикселей или больше
- Квадратная форма работает лучше всего
- Используйте контрастные цвета
